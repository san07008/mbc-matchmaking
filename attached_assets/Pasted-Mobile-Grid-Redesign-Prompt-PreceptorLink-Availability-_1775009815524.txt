Mobile Grid Redesign Prompt - PreceptorLink Availability Survey
Context
The current availability grid in PreceptorLink's preceptor survey is not mobile-friendly. On phones, users face a dense, scrollable table with 40+ buttons (8 time slots × 5 days) that's difficult to navigate, read, and interact with.
Problem Statement

Current UX: Single dense table, horizontal + vertical scrolling required on mobile
Issue: Buttons are small, layout is cramped, users can't easily see a full day's availability at once
Goal: Create a responsive, touch-friendly interface that works beautifully on all screen sizes

Design Requirements
1. Desktop (1024px and up)

Layout: Keep the current grid view as-is (full 5×8 table)
Reason: Admins and users on desktops benefit from seeing the full week at once
No changes to current desktop experience

2. Tablet (768px - 1023px)

Layout: Accordion-style OR two-column grid
Preference: Accordion (one day per accordion item)
Details:

Each day is an expandable section
Default: Monday expanded, others collapsed
Title shows: "Monday, Mar 27" + count of selected hours "(2 selected)"
Click to expand/collapse



3. Mobile (under 768px)

Layout: Accordion-style, one day at a time
Key Features:

Full-width accordion panels
Each panel shows day name + date
Large, touch-friendly buttons (minimum 44px × 44px)
Time slots displayed as a vertical list of toggle buttons
Clear visual distinction between selected/unselected
Smooth animations on expand/collapse
Sticky summary at top or bottom showing total selected hours

  {/* Sticky Header */}
  <div className="sticky top-0 bg-white shadow-sm p-4">
    <h1>Preceptor Availability Survey</h1>
    <p className="text-sm text-gray-500">Week of Mar 27 - Mar 31</p>
  </div>

  <div className="flex-1 overflow-y-auto p-4 md:p-8">

    {/* DESKTOP: Full Grid (hidden on mobile/tablet) */}
    <div className="hidden lg:block">
      <AvailabilityGrid surveyDays={surveyDays} />
    </div>

    {/* MOBILE/TABLET: Accordion */}
    <div className="lg:hidden">
      {surveyDays.map((day) => (
        <AccordionDay
          key={day}
          day={day}
          times={SURVEY_TIMES}
          availability={availability[day]}
          onToggle={(time) => toggleSlot(day, time)}
          selectedCount={Object.values(availability[day] || {}).filter(Boolean).length}
        />
      ))}
    </div>
  </div>

  {/* Sticky Summary (Mobile) */}
  <div className="sticky bottom-0 md:hidden bg-white border-t p-4 flex justify-between items-center">
    <span className="text-sm font-semibold">Selected: {totalHours} hours</span>
    <button className="px-6 py-3 bg-orange-500 text-white font-bold rounded-lg">
      {submitted ? 'Update' : 'Submit'}
    </button>
  </div>

  {/* Desktop Submit Button */}
  <div className="hidden md:flex justify-end p-8 gap-4">
    <button className="px-8 py-3 bg-orange-500 text-white font-bold rounded-lg">
      Submit Availability
    </button>
  </div>
</div>
Accordion Component Specifications
AccordionDay Props
typescriptinterface AccordionDayProps {
  day: string;                    // "Monday, Mar 27"
  times: string[];                // ["9 AM", "10 AM", ...]
  availability: Record<string, boolean>; // { "9 AM": true, "10 AM": false, ... }
  onToggle: (time: string) => void;
  selectedCount: number;          // Number of selected slots for this day
  isDefaultOpen?: boolean;        // First day opens by default
}

Performance Considerations

Lazy Rendering: Only render expanded day contents
Memoization: Wrap AccordionDay in React.memo() to prevent re-renders
Transition Performance: Use CSS transforms instead of height changes (if possible) for smoother animations
Touch Optimization: Debounce rapid taps to prevent double-submission
